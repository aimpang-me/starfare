Rule 1 · Every number has a source

Each number in the quote must appear in the tool output or in the rider's own words. Rounding is fine if it rounds the right way (9.18 can be 9.2). Dates must match exactly.

Rule 2 · Every ride survives the re-fly

An independent physics checker re-flies each offered route. It passes only if the final miss is under 1 km and the correction is under 500 m/s.
